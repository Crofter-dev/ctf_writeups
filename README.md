## About

Each write-up documents the investigative process for its room — the search queries, tools, and reasoning used to reach each answer — rather than just listing flags. The goal is to keep these useful as reference material for similar techniques (Event ID mapping, Sysmon triage, PCAP/C2 analysis, XOR known-plaintext attacks) in future rooms or real investigations.

## Structure

Each write-up follows the same format:
- **Overview** — what the room covers and the skills it tests
- **Investigation** — question-by-question breakdown with the exact search query or command used
- **Key Lesson** — the underlying technique or concept the room reinforces
